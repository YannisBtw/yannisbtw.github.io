Создание и развертывание статического сайта на базе MkDocs с публикацией в интернете.

🎯 Цель работы

Освоить процесс создания статического сайта с использованием генератора документации MkDocs, а также изучить принципы публикации сайта без серверной части.

🧠 В ходе выполнения работы были освоены

  • создание статического сайта из Markdown-файлов;
  • организация структуры документации проекта;
  • использование системы контроля версий Git;
  • работа с удалёнными репозиториями;
  • сборка статического сайта;
  • публикация сайта через SourceCraft Sites;
  • настройка конфигурационного файла mkdocs.yml.

🛠 Используемые технологии

  • Python
  • MkDocs — генератор статических сайтов
  • Git — система контроля версий

💻 Локальный запуск проекта

1. Клонирование репозитория

git clone https://github.com/YannisBtw/yannisbtw.github.io
cd yannisbtw.github.io

2. Создание виртуального окружения

python -m venv .venv

3. Активация

Windows:

.venv\Scripts\activate

4. Установка зависимостей

pip install mkdocs

5. Запуск локального сервера

mkdocs serve -f site/mkdocs.yml

После запуска сайт доступен по адресу:

http://127.0.0.1:8000

⚙️ Сборка сайта

mkdocs build -f site/mkdocs.yml -d ../docs --clean

👉 После выполнения команда создаёт готовый HTML-сайт в папке docs/.

🚀 Публикация сайта

🔹 SourceCraft Sites (основной способ)

Сайт публикуется из папки docs/ с помощью конфигурации:

site:
  root: "docs"
  ref: "master"

После выполнения:

git add .
git commit -m "update site"
git push sourcecraft master

сайт автоматически обновляется.

🔹 GitHub Pages (дополнительно)

Настройки:

  • ветка: main
  • папка: /docs

🌐 SourceCraft Sites

Сайт доступен по адресу:

👉 https://shadowkreys.sourcecraft.site/shadowkreys-sourcecraft-site/

Особенности:

  • не требует серверной части;
  • автоматическое обновление при push;
  • работает по HTTPS;
  • использует готовый статический HTML.
